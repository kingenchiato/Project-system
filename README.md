# STRIDE — 案件進行管理システム

クライアント提案（予算・スケジュール・タスク・担当管理＋AI活用）に基づく、ブルー基調の進行管理デモです。

## 機能

- ダッシュボード（進捗・予算・マイルストーン・AI注意点）
- プロジェクト管理（追加・フィルタ）
- タスク管理（カンバン / リスト、ステータス変更）
- スケジュール（カレンダー + マイルストーン）
- 予算管理（費目別計画対実績）
- 担当管理（稼働率・タスク割当）
- AIアシスタント（自然文での状況・リスク・予算提案）

起動時に約8秒のプレミアムローディング演出があります。

## 開発

```bash
npm install
npm run dev
```

## GitHub Pages デプロイ
